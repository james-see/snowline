# Art Direction

Cold alpine: deep navy atmosphere, ice highlights, sparingly used sun-gold. Display: Syne. Body: DM Sans.

Avoid: purple-on-white gradients, cream+terracotta AI defaults, broadsheet layouts, emoji UI, white-out fog washes.

Snow reads as substance (powder/packed/ice), not flat white. Mountains need fog silhouette depth. Gameplay frames must show terrain + rider — never blank sky (P0).

Critic visual bar: local refs under `refs/snowboard/` (`npm run refs:fetch`) — SSX 3 / Steep stills + real powder/air photos. Score against those, not against “slightly better than last capture.”
